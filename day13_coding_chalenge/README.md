# Responsive Card UI

## 📌 What It Does
This project displays a stylish, fully responsive card UI layout that adapts across all screen sizes. Each card contains an image, title, description, and a button.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Media Queries)
- Optional: JavaScript (for button interactivity or hover effects)

## 🚀 How to Run
1. Download or clone the project folder.
2. Open the `index.html` file in any modern web browser.
3. Resize your browser window to see the responsiveness in action!

## 💡 Features
- Responsive layout
- Stylish cards
- Clean and modern UI
