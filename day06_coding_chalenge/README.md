**🧩 Project Name:**
Text-to-Speech App

**🎯 What It Does:**
This app allows users to type or paste text, then click a button to have the text spoken out loud using your browser’s built-in Text-to-Speech engine via the Web Speech API.

**🛠️ Tech Used:**
HTML – Page structure

CSS – Styling and responsive layout

JavaScript – Speech logic using Web Speech API

**▶️ How to Run:**
Open a text editor like VS Code or Notepad++.

Create a new file and name it index.html.

Paste the full code above into the file.

Save and open the file in a web browser (Chrome or Edge preferred).

Type something and click Speak — the browser will read it aloud!
