Typing Speed Test


Features:
- Presents a random sample sentence.
- Start button begins timer; live updates of time, WPM, and accuracy.
- Test ends when typed length >= sample length.

How to use:
1. Save & open typing.html.
2. Press Start, type the text shown, and watch WPM and accuracy update.
