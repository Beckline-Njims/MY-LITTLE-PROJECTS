Bookmark Saver


Features:
- Add bookmarks (title + URL). If protocol missing, https:// is prepended.
- Search saved bookmarks.
- Open or delete bookmarks.
- Stored in localStorage.

How to use:
1. Save/open bookmarks.html.
2. Add a title and URL then click Add.
3. Use Search to filter saved bookmarks.

technologies
1. html
2. css
3. javascript
