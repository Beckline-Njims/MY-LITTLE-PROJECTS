# Country Search App (Using Rest Countries API)

## Description
This is a simple web app that allows you to search for countries by name using the free Rest Countries API. It fetches live data online and displays matching country names and their flags.

## Features
- Real-time search with debounce to reduce API calls
- Displays country name and flag
- Handles "no results" and network errors gracefully
- Clean and responsive design

## How to Run
1. Save the file `country-search.html`.
2. Open it with any modern browser (Chrome, Firefox, Edge, Safari).
3. Start typing the name of a country.
4. Results update dynamically from the online Rest Countries API.

## API Used
- [Rest Countries API](https://restcountries.com/) (Free, no API key required)
