**Project Name:**
Dice Roller App

** What It Does:**
This is a fun and interactive digital dice roller. With just a button click, it generates a random dice face (⚀ to ⚅) to simulate rolling a physical die.

Great for:

Board games

Practicing JavaScript randomness

Beginner JavaScript projects

Simple user interface design exercises

**🛠 Tech Used:**
HTML: Page structure

CSS: Styling and layout

JavaScript: Dice logic (random number generation and DOM update)

Emojis: Dice faces (⚀, ⚁, ⚂, ⚃, ⚄, ⚅)

🧪 Features:
Random dice face shown each time the button is clicked

Clean, responsive UI with centered layout

Smooth hover animation on button

Emoji-based dice visuals (no image files needed)
