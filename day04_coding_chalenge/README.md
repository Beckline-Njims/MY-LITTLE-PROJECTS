**Project: Tip Splitter App**

**What it does:**
Takes total bill amount, tip percentage, and number of people.

Calculates the tip per person and total per person.

 **Technologies used:**
 
HTML (for structure)

CSS (for styling)

JavaScript (for calculation logic)

** How to run:**

Save the files as:

index.html

style.css

script.js

Open index.html in a browser.

Enter bill, tip %, and number of people, then click Calculate.
