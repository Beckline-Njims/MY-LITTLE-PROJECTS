**Project: Counter App**

 **What it does:**
This app allows users to increase, decrease, or reset a numerical counter using buttons.

** Technologies used:**
HTML (for structure)

CSS (for styling)

JavaScript (for interactivity)

**How to run it **

Save all three files in the same folder:

index.html

style.css

script.js

Open index.html in your browser.

Click the buttons to interact with the counter.
