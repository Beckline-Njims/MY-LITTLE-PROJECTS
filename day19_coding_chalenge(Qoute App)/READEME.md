# Quote Generator App (API)

## Description
This app fetches a random quote from the Quotable API every time the button is clicked.

## Technologies
- HTML
- CSS
- JavaScript (Fetch API)
- External API: https://api.quotable.io/random

## How to Run
1. Open `index.html` in a browser.
2. Click "New Quote" to fetch a random quote from the internet.
