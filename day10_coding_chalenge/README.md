** Accordion Project**

A simple and responsive **Accordion** built using HTML, CSS, and JavaScript.
Click on each section to expand or collapse its content. Only one section is open at a time.

##  Features
- Expand/collapse content on click  
- One section opens at a time (auto-close others)  
- Smooth animations using CSS transitions  
- Responsive and clean design

##  Technologies Used

- **HTML** – for the structure  
- **CSS** – for styling and animations  
- **JavaScript** – for interactivity and toggling
- 
## 📦 How to Run

1. Create a file named `index.html`  
2. Copy and paste the full code above  
3. Open `index.html` in any modern web browser  
4. Click on the sections to expand or collapse them
