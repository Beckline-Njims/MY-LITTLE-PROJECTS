** Tab Section Project**

This project is a simple and responsive **Tab Component** built using 
**HTML**, **CSS**, and **JavaScript**. It allows users to switch between different sections of content by clicking on tab headers.

** Features**

- 💡 Three responsive tabs: Home, About, Contact
- 🎨 Styled with basic CSS and transitions
- 🧠 JavaScript controls tab switching logic
- 📱 Mobile-friendly design

** Technologies Used**

- **HTML5** – for markup structure  
- **CSS3** – for styling and layout  
- **JavaScript (Vanilla)** – for interactive tab switching

** How to Run This Project**

1. **Download or clone** this repository.
2. Open the file `tabs.html` in any web browser.
3. Click on the tabs to view different content.
