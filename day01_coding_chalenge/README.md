**What It Does**
The Simple Calculator App is a web-based tool that allows users to perform basic arithmetic operations:

Addition

Subtraction

Multiplication

Division

It features a modern design and interactive number buttons, providing instant calculation results.

** Technologies Used**
HTML – for the structure of the calculator interface.

CSS – for styling, layout, and responsiveness.

JavaScript – for handling logic, button actions, and real-time calculations.

** How to Run It**
✅ Option 1: Run Locally
Create a folder on your computer, e.g., calculator-app

Inside the folder, create these three files:

index.html

style.css

script.js

Copy and paste the HTML, CSS, and JS code into the respective files.

Open index.html with any web browser (e.g., Chrome or Firefox).

✅ Option 2: Run Online
Go to https://codepen.io/ or https://jsfiddle.net/

Copy and paste:

HTML in the HTML section

CSS in the CSS section

JavaScript in the JS section

Click Run to test it live.
