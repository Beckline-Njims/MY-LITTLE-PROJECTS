**Project Name:**
Digital Clock

** What It Does:**
A simple, real-time digital clock that displays the current time in HH:MM:SS AM/PM format.
It updates automatically every second using JavaScript.

** Technologies Used:**
HTML – Structure of the clock

CSS – Styling and layout

JavaScript – Logic to get current time and update it live

** How to Run It:**
Open a text editor like VS Code or Notepad++.

Copy the following code into a file and save it as digital-clock.html.
Double-click the file or open it in any browser (Chrome, Firefox, Edge).

You’ll see your digital clock running and updating in real-time.
