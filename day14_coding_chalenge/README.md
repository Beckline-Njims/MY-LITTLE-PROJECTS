# Multi-Step Form

A simple, responsive multi-step form using HTML, CSS, and JavaScript.

## 📌 Features

- Three-step form with input validation.
- Smooth transitions between steps.
- Visual progress indicator.
- Custom CSS design.
- Final submit alert.

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 How to Run

1. Clone or download the project folder.
2. Open `index.html` in a browser.
3. Fill in each step and navigate using **Next** and **Back** buttons.
4. On the final step, click **Submit** to trigger a success alert.
