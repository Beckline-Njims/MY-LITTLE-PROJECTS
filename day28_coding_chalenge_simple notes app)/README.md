Simple Notes


Features:
- Create new notes with title.
- Select a note to edit content.
- Save and Delete notes.
- Stored in localStorage.

How to use:
1. Save & open notes.html.
2. Type a title and press New to create.
3. Select a note, edit text, click Save.

Techmologies
1. html
2. css
3. javascript
