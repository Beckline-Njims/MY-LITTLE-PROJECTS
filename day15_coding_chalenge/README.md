# Weather App 🌦️

A simple weather application built with HTML, CSS, and JavaScript using the OpenWeatherMap API.

## Features
- Fetch current weather based on city input
- Displays temperature and weather conditions

## Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Setup
1. Clone this repo
2. Replace `"const_API_KEY"` in `script.js` with your actual API key
3. Open `index.html` in your browser
