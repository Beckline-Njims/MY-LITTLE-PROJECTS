 **Project Title:**
 
 Modal Popup
 
**What It Does**

This is a basic modal popup built with HTML, CSS, and JavaScript. A modal appears in the center of the screen when the user clicks a button. It can be used for alerts, notifications, or forms.

** Features*
Opens a modal popup on button click

Closes the modal when the close button is clicked

Centered, mobile-friendly design

Styled with a modern look using CSS

** Tech Used**
HTML for structure

CSS for styling

JavaScript for interactivity

 **How to Run It**
 
Open the project folder.

Double-click the index.html file to open it in your browser.

Click the "Open Modal" button to see the popup in action.

Click the "Close" button to hide the popup.
