# 💰 Expense Tracker

A simple web app to track your daily expenses using HTML, CSS, and JavaScript. It stores data in your browser using `localStorage`.

## ✅ Features

- Add new expense (name, amount, date)
- View all expenses in a list
- View total expenses
- Delete an expense
- Saves data in browser (localStorage)
