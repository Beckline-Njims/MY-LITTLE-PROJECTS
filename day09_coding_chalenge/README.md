Project Name : Image Slider

**Features**

⏭ Auto slide every 4 seconds

⬅️➡️ Manual navigation with previous/next buttons

🎨 Smooth transitions with fade-in effects

📱 Responsive design for all screen sizes

🔄 Looping through images seamlessly

**🛠️ Technologies Used**

HTML – structure of the slider

CSS – styling and layout

JavaScript – functionality and transitions

**📂 How to Run**

Download or copy the code

Create a file named index.html

Paste the code into it

Open the file in any web browser

Enjoy the slider in action!
