**project name **

Rock , Paper, Scissors App

**What It Does:**
Lets users play Rock, Paper, Scissors against the computer.

Tracks scores after each round.

Displays fun emoji-based feedback and winner message.

** Tech Used:**
HTML: Structure of the game

CSS: Layout and styling

JavaScript: Game logic (random choice, result checking, score update)

 **How to Run:**
Open any text/code editor.

Save the above code as index.html.

Double-click the file or open it in a browser.

Click any button to play!
