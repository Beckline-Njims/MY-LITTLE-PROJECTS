# GitHub User Fetcher 👤

A small web app that fetches public data of any GitHub user by username.

## Features
- Fetches and displays user avatar, name, repos, followers, and profile link

## Tech Stack
- HTML
- CSS
- JavaScript
- GitHub REST API

## How to Use
1. Clone the repo
2. Open `index.html` in your browser
3. Enter any GitHub username to fetch their details
