# 🌍 Country Info Fetcher

A simple web app to search and display information about countries using the [REST Countries API](https://restcountries.com/).

## 💡 Features

- Search by country name
- Displays:
  - Flag
  - Capital
  - Region
  - Population
  - Currency
  - Languages

## 🛠️ Technologies

- HTML
- CSS
- JavaScript (Fetch API)
