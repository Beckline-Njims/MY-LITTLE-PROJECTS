# Sticky Navbar

## 📌 Project Description
A simple sticky navigation bar that stays fixed at the top when you scroll. Built using pure HTML and CSS.

## 🛠️ Tech Used
- HTML5  
- CSS3  
- (No JavaScript needed)

## 🚀 How to Run
1. Download the files.
2. Open `index.html` in your browser.
3. Scroll the page — the navbar will stick to the top.

## ✨ Features
- Sticky top navbar
- Responsive layout
- Smooth navigation links
- Stylish hover effect

## 🔖 Sections Included
- Home
- About
- Services
- Contact
