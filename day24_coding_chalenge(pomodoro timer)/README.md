Pomodoro Timer

Features:
- Work and break durations adjustable (minutes).
- Cycle count configurable.
- Start / Pause / Reset.
- Auto-switches between work and break, stops when cycles completed.
- Saves settings and state to localStorage.

How to use:
1. Save/open in browser.
2. Change durations if desired.
3. Click Start to begin. Use Pause or Reset as needed.
Technologies
1. html
2. css
3. javascript
