Todo App with Filters

Features
- Add tasks, edit by clicking on text (blur to save).
- Toggle completed, delete tasks.
- Filters: All / Active / Completed.
- Save tasks in localStorage to keep between reloads.
- Export button shows JSON of todos.

How to use
1. Save as todo.html and open in a browser.
2. Add tasks using input + Add or Enter.
3. Click text to edit; click checkbox to mark done.
Technologies
1. html
2. css
3. javascript
