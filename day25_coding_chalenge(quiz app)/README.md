Quiz App


Features:
- Multiple-choice quiz with navigation (Prev/Next).
- Select answers and Submit to get a score.
- Simple data array — edit or add questions inside the file.

How to use:
1. Save & open quiz.html.
2. Edit the `data` array in the JS to add your own questions.
Technologies
1. html
2. css
3. javascript
