# Joke Generator 😂

A simple app that fetches and displays a random joke using the Official Joke API.

## Features
- Click button to generate a new joke
- Uses `official-joke-api.appspot.com`

## Tech Stack
- HTML
- CSS
- JavaScript

## Setup
1. Clone the repo
2. Open `index.html` in your browser
3. Click the button to laugh!
